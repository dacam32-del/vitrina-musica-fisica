# Vitrina Musical
Vitrina virtual de la colección de música física de David (vinilos, CDs, casetes).
Sitio: https://dacam32-del.github.io/vitrina-musica-fisica/

## Agregar una pieza
1. Fotos en `img/` como `MUS-00N.jpg`, `MUS-00N-2.jpg`, … (optimizadas, ~1400px).
2. Agregar un objeto a `data.json` copiando la estructura de `MUS-001` (pmin/pmax en CLP numéricos para filtros).
